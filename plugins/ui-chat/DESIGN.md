**消息流**

- 用户：右、浅灰气泡、圆角 8、最大 72% 宽；助手：左、整宽、markdown 渲染 + 消毒。
- **内容 parts 分发（全能口径）**：按消息 part 的 `type` 分发到渲染器——`text`(markdown) / `image`(缩略 + lightbox) / `video`(缩略 + 播放器) / `audio`(播放条) / `file`(文件卡) / 工具卡（挂载点）。字节经入站 `asset.get {sha256}` 取（缺失 → 占位，见资产回放语义），**世界只存引用**。
- **媒体显示上限（ui-design §16.7）**：图片缩略 ≤320×240、视频缩略 ≤320×180、音频条 40px 高 × ≤480 宽、文件卡单行 34px；超出进 lightbox / 详情。媒体一律 `loading="lazy"`，音频 / 视频**不自动播放**（需点击）；媒体加载失败 → 占位（`--c-bg` + alert-circle）+「媒体加载失败」+ [重试]。
- 附件块：图片缩略（点击放大）、**视频缩略（点击播放）**、音频播放条、文件卡片；工具卡由各工具插件自带渲染器注册（见下「暂不做的渲染器」）。
- 脚注：**token 用量可展示（2026-09-18 修正，2026-09-19 定源）**——当条助手消息的 usage **直接读 `chat.history` 消息 def 的 `meta.usage`**（`#11` 已存），以 12px `--c-text-3` 常显该条 token 量；无 `meta.usage` 则不显示。**不需要新事件源**（原候选「per-message usage 事件源」据此结清）；模型名不进脚注（工具栏已常显当前模型）；另有 复制 / 重试 两枚 16px 图标按钮（hover 消息淡入 100ms）。
- **复制反馈（2026-09-19 补）**：点击复制 → 图标**就地** `copy` → `check` 交叉淡化 100ms，保持 **1.2s** 后回退 `copy`；同时 `aria-live="polite"` 播报「已复制」（文案走 `messages.v1.json`）。**不走 toast**（克制，见 ui-design §12 注）；复制失败（剪贴板不可用）→ 图标变 `alert-circle` + 行内 12px danger 文字「复制失败」，可重试。
- **紧凑：正文 14/22、间距 16；滚动贴底 / 上滑冻结 / 回到底部胶囊；跨天日期分隔；会话切换 150ms 淡入淡出。
- **代码块（ui-design §16.8）**：等宽 `--font-mono` 13/20、圆角 6、底色 `--c-bg`（与 `--c-surface` 分层）、水平滚动不换行；**不做语法高亮**（纯单色 `--c-text`，不引彩色 token）；行号不做；复制按钮复用脚注按钮。
- **链接（ui-design §16.6）**：markdown 内链接一律 `target="_blank" rel="noopener noreferrer"`，交系统默认浏览器打开，不改产品内路由；代码块 / 代码段内文本不自动链接化。
- **日期分隔（ui-design §16.9）**：跨天插入 12px `--c-text-3` 居中分隔，格式 `今天` / `昨天` / `YYYY-MM-DD`（同年省略年、跨年含年），本地时区。
- **长列表与「新消息」（2026-09-19 补）**：
  - **窗口化**：消息数 > 200 时只渲染视口 ±1 屏缓冲（虚拟化），**不改变 DOM 语义与可选中 / 可复制**；工具卡默认收缩（节点少），展开态超出视口时延迟渲染。**跨窗选择不支持**（选区仅当前窗口，登记限制，ui-design §16.5）。
  - **翻页加载（ui-design §10）**：滚顶拉上一窗时列表顶部内联呼吸条（2px × 32px，不遮消息）；**到底显示「没有更多了」**（12px `--c-text-3`），不静默。
  - **上滑冻结时的「↓ N 条新消息」**：用户上滑（不再贴底）且新内容到达 → 回到底部胶囊**就地变为**「↓ N 条新消息」（accent 底 + 计数，数字交叉淡化 100ms）；点击平滑滚到底并清零。**仍在贴底时**新内容自动贴底，不出现该胶囊。`aria-live="polite"` 播报一次。
- 生成中：呼吸条 -> 逐段追加 + 1px 光标；>8s 显示「仍在生成…」；终止后本地保留已生成部分并标注「已取消」（宿主丢弃该 run，刷新后不保留）。
- 内联错误条：流末尾 + 左 3px danger 竖线 + 「重试」；世界里的历史失败以 system 消息低调渲染（灰条 + 错误码人话）。

**视觉细节（2026-09-18 逐插件定案）**

- **用户气泡**：右对齐、`--c-selection` 灰底、四角一致 `--radius-lg`(8)、≤72% 宽、无边框。
- **助手消息**：左侧整列宽（≤720 居中列）、无底无框，markdown 直接排在页面底色上——「有色=我说的，无色=它说的」。
- **复制 / 重试**：16px linear 图标按钮（**命中区 ≥24×24**，ui-design §16.3），默认 `--c-text-3`、hover `--c-text`，五态照 ui-design §9。
- **图片 lightbox**：点缩略图 → 视口居中 overlay（遮罩 .28、150ms 淡入、`--shadow-pop`）；原图限 90vw×86vh；**滚轮 / 捏合缩放 0.2×–4×**（缩放中心=指针位置）、双击 1×↔2×、超出视口可拖拽平移（grab 光标）、右上关闭图标(x 20px)、ESC / 点遮罩关闭；原图加载期为块级呼吸条（§10 等待态）。**焦点管理（ui-design §16.2）**：打开时焦点移入 lightbox、锁背景滚动，关闭时焦点**归还缩略图**；层级 `--z-lightbox`（§16.11）。
- **视频播放**：缩略 + 播放按钮 → 就地展开播放器（同 lightbox overlay 规格：遮罩 .28、150ms 淡入、`--shadow-pop`、ESC / 点遮罩关闭）；控件用原生 `<video controls>`（不自建）；加载期块级呼吸条（§10）。
- **等待态**：历史加载 = 块级呼吸条；首 token 前 / >8s 文案 / 终止标注按已锁口径 + ui-design §10；任何等待不得静默无限。
- **空会话态（2026-09-18 补）**：历史加载完成且消息数为 0 时，消息列垂直居中略偏上渲染两行——14px `--c-text-2`「开始新对话」+ 12px `--c-text-3`「输入消息开始，或先用 + 添加附件」；**无插图、无大字（§10 空态规范的「无图标变体」）**；首条消息出现时 150ms 淡出。
- **工具调用 / 结果渲染（挂载点，本轮定契约）**：**各工具插件自带渲染器**——工具插件在 `describe` 里回 `render` 描述符（`form` / `label` / `summary` / `tone` / `detail` / `live`，见 #27「工具卡渲染」），#27 派发时把它**快照进工具调用 / 结果消息 part**（写 #11）；本插件**只按描述符画**，**不认识任何具体工具**。
  - **两种形态**：`form:"line"` = 消息流里一行（如 `read`：一行「read 文件名」，不可展开）；`form:"card"` = 可折叠卡片（折叠态 = `label + summary`，展开态 = `detail` 渲染器）。
  - **质感 `tone`**：`ghost`（近乎透明；只读检索类：`grep` / `glob` / `websearch` / `webfetch`）/ `plain`（常规；`edit` / `shell` / `webbrowser`）/ `solid`（实底；高危写类 `plugin.write` / `orchestration.propose`）。
  - **`detail.kind` 渲染器**：`text` / `code` / `diff`（逐行对比：新增绿 / 删除红 / 修改黄 + 上下文折叠）/ `matches`（`path:line  片段`）/ `paths` / `list` / `table` / `json` / `file` / `image`（资产引用 + lightbox）/ `terminal`（等宽，stdout / stderr 分色 + 退出码）/ **`question`（交互：单选 / 多选 / 自定义输入 / 提交，见下）**。
  - **`question` 交互渲染器（#48）**：渲染 `#48 question` 的提问卡（问题 + 选项 + 自定义输入 + 提交）；提交经**入站面**写槽 + 调 `question.answer`（**按名调用、不需 pins**）；**已答折叠成一条记录**（问 + 答），随历史留存可回放。卡在 `main` 槽消息流内，不抢 dock / overlay。**键盘可达（ui-design §16.2）**：单选用 `role="radiogroup"` + 方向键、多选用 checkbox 语义 + Space、`Enter` 提交当前；提交中按钮走按钮内等待态（§10），失败落行内 danger + [重试]。
  - **动态输出（`live:true`）**：收到 `tool.start` 即开卡，按 `call_id` 追加 `tool.delta` 分片（如 `shell` 的 `pip install` 进度）；`tool.end` 收尾；run 结束以消息 part 的**定稿结果**替换实时态（**回放只读定稿**，事件不落账）。
  - **降级**：无 `render` / 未知 `kind` → markdown 文本降级渲染（不空白、不报错）。
  - **为什么快照**：描述符随消息落 #11 ⇒ 展示与回放确定，换工具插件 / 换工具集都不影响旧消息渲染。
  - **升级路径**：需要真自定义组件时，给工具插件加**浏览器侧渲染模块**投递面（headless 子应用向本插件注册渲染器）；`render` 描述符仍是其声明面。
- **推理卡片 / 气泡**：本轮仍不做（只谈意图的口径下，推理默认不进展示流）。

## 线程视图（按 `kind` 分派，2026-09-19；群聊 / 工作流细节 2026-09-19 补）

main 槽按当前线程的 `kind` 分派渲染（**不新增 slot**，见 `docs/plans/threads-design.md` §四）：

| `kind` | 渲染 |
| --- | --- |
| `main` / `subagent` | 普通对话（现有消息流；子代理顶部一条 12px `--c-text-2` 头「<人格名> · 由 X 触发」，整宽、无底、不占气泡） |
| `group` | **群聊**（见下） |
| `workflow` | **步骤卡**（见下） |

### 群聊（`group`）

- **发言者标识 = 首字母圆标 + 名**（§8 禁彩色 / 禁 emoji，故不做彩色头像）：24px 圆、`--c-selection` 底、首字母 12px `--c-text`；圆标右侧名 12px `--c-text-2`。同一发言者连续消息只在首条显名，后续缩进对齐。
- **「我」的消息**仍走既有用户气泡（右对齐、selection 底）；**参与者消息**左对齐、圆标 + 名在气泡上方，气泡底 `--c-surface` + 1px `--c-border`（与助手无底整宽区分）。
- **圆桌轮转**：按 transcript 顺序渲染；**当前发言者**（正在生成）圆标外圈 1.5px accent 环 + 呼吸（§10 呼吸族，reduced-motion 静态），生成完移除。
- **未读锚点**：进入群聊线程时若有新消息（`group.message` 增量、`last_seen` 落后），在首条新消息前画 1px accent 分割线 + 「以下为新消息」，滚过即淡出。
- 增量订阅 `group.message`（**按 `thread` 过滤**）；历史仍以 `chat.history` 为准。

### 工作流（`workflow`）

- **步骤卡**（`main` 内）：当前步骤名 14px + 「第 i / N 步」12px `--c-text-2` + 状态（运行中呼吸点 / 成功 check / 失败 x / 等待审批 warning 点，§11 三重编码）；下方 1px 细进度条（accent 前景色）。
- **展开 = 节点列表**（只读）：逐节点 `node_index` + 契约名 + `impl` + 状态（成功 / 失败 / 跳过）。**不是图形化图**（与 #17 S13「不做图形化编辑器」口径一致；原「点开看 #33 图」措辞作废）。
- **失败节点**：inline 显示拒绝码人话（`messages.v1.json`）+ [重试]（若策略允许，走 #33 重入）；**回退 / 回滚不在本卡**——结构性回滚在 #17 S13。
- 增量订阅 `workflow.step`（**按 `thread` 过滤**）。
- **`workflow` 线程不组装消息历史**（#13 口径），故本视图不渲染消息气泡。

- 线程切换由 #46 `ui-threads` 经 `api.uiState` 广播 `active_thread`（纯视图态）；本插件订阅该键，按 `chat.history {conversation}` 重拉对应线程并渲染。侧栏点击历史会话走 `session.select` 写世界 `current`，本插件随 `chat.history` 跟随，无需感知选择动作。**切换加载态（ui-design §10）**：主区 150ms 淡入 + 顶部细呼吸条（不遮消息、不整屏遮罩）。
- **登记**：#11 会话加 `kind` 等字段（版本提升，见 #11）；`detail.kind:"question"` 的提交入口来自 #48（按名调 `question.answer`）。
