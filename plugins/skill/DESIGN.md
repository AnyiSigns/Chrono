## 数据契约 `schema/skill.json`

```jsonc
{ "version": 1,
  "skills": [
    { "id": "sk-…", "name": "写测试",
      "description": "为改动补单元测试的步骤与约定",
      "triggers": {
        "keywords": ["测试", "test", "单测"],       // 命中任一即候选
        "file_globs": ["**/*.test.ts", "tests/**"], // 上下文涉及这些文件即候选
        "explicit": ["@测试"]                        // 用户显式点名
      },
      "scope": { "kind": "workspace", "workspace_id": "w1" },  // 缺键 ≡ {kind:'global'}
      "body": "…步骤 / 约定 / 示例…",                // 纯文本说明（不含可执行内容）
      "enabled": true,
      "at": "…" } ] }
```

- 白名单子集无 `oneOf` / `$ref`，`triggers` 形状写在 `description`、由**写入端**（#17 S11）保证（宿主 v1 不校验身份数据）。
- **不含可执行内容**（验收 4）：技能只有说明文本；要执行走沙箱与工具族。
- 技能数量少，**内联列表**（不做 #11 那种链式；写放大可接受）。

## 触发（结构化 + #33 判定）

- **机械候选**：`keywords`（对当前轮文本）/ `file_globs`（对上下文涉及文件）/ `explicit`（用户 `@` 点名）三者命中任一 → 该技能成为**候选**。
- **判定**：`#33` `prompts` 保留 id `skill_select` 判定注入哪些候选（#33 侧已声明）；`context.assemble` 按 scope 过滤候选写 `bag.skills` 交 #13——`{scope, keywords, file_globs, explicit}` 三触发字段 + 描述 + body（2026-09-20 修订）。**#33 是唯一选择者**，本插件不判定。
- 选中的技能说明由 **#33 `context.assemble` 写进 `bag.skills`** 交 `#13` 作为**技能片段**注入（各成一条消息；#13 已有「技能片段」版本提升）。**#13 不读 `#36` 投影**（D8；否则就认识了技能身份）。

## 作用域（`scope`，与 #33 Scope / #35 人格同形）

```jsonc
"scope": { "kind": "global" | "workspace" | "session", "workspace_id"?: "w1", "session_id"?: "c1" }
```

- 缺键 ≡ `{kind:'global'}`（向后兼容原 `workspace` 字段语义：给了 workspace 就是仅该工作区）。
- **三处同一形状**：#33 的 Scope 实例、#35 的人格实例、本身份的技能——**同一个 `scope` 形状，同一条过滤规则**。
  好处：用户说"这条技能 / 这个子代理只用于本项目"时，两边写法一致，#33 也只需一套过滤逻辑。
- **强制点在 #33，不在本身份**：#33 按当前会话的 `workspace_id`（经 #11 → #41 解析）过滤候选，
  `workspace` 技能在其它工作区**不进候选集**。本身份只**存**该字段，不做判定（纯数据身份）。
- **口径：图通用，专门化落数据层**。#33 的图不按工作区分叉（否则每工作区样本量被除、进化环空转）；
  跨项目差异由 `scope` 过滤的**技能 / 人格 / 实例**承载。

## 写入

- 入口 = `#17 ui-settings` **S11 技能页**：客户端直写 `put` + `add_gen`（同 config / workspace 数据身份一族），形状校验在写入端。
- 写入者不读投影、不写世界本体之外的东西。

- **#33 loop-policy**：读投影 + 按准则（**#33 `prompts` 保留 id `skill_select`**）选择（**投影读，非 pins**——纯数据身份不参与路由，§1.2 第 6 条）；选中技能由 #33 `context.assemble` 写 `bag.skills` 交 #13（D8）。

  与 #33 Scope 实例、#35 人格共用同一过滤规则；过滤由 #33 在选候选时执行，本身份只存字段。

  **仍是"结构化触发"的先例来源**，#33 的 `when` 边条件与之形状不同（**服务内声明式规则引用**，D1），不要混用。
