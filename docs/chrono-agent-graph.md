# ChronoAgentGraph：自适应可进化 Agent 图编排（设计）

> 本文是**设计**：ChronoGraph 是什么、边界在哪、有哪些写死的口径与不变量；**不含实现步骤、算法伪代码与具体数值**。
> 本文只引用设计文档，不引用任何计划文档。
> 本文是**总览与纲领**；机制细节见 §五 文档地图与目录树。
>
> **定位**：面向**复杂任务**的**可进化 agent 运行时架构**。核心思想：**图不固定**，执行拓扑由**编排模型（不含 LLM）**
> 在运行时现场生成；控制层可训；节点池声明式、惰性训练；搜索与生成混合；所有变更可回退可控。
>
> **独立实验树** `experiment/ChronoGraphLab/`，**standalone、不接内核**；账本 Entry **字段形状**与内核对齐（`{seq, prev, op, args, argsHash, by, ref?, at}` + 链式哈希），但 **op 集合不同**（实验 defs 链 8 op：`declare`/`put`/`add_ver`/`set_active`/`quarantine`/`accept`/`snapshot`/`audit`；内核 op 共 10 种：`put`/`add_identity`/`add_gen`/`set_active`/`retire`/`fork`/`graft`/`batch`/`note`/`snapshot`，其中 `batch` 为合成外壳、`note` 为留痕，**迁移面对手按 8 个原语计**；语义 1:1 可直接对上的是 `set_active`/`snapshot`，`put` 同名但 slot 语义仍须逐项映射）且实验双链（defs/events）vs 内核单链；**两侧按 8 个原语计 ⇒ 迁移映射层接近一对一**，但仍须经 **op 语义映射层**，**非"只换存储不换语义"**（`declare` 的七个 `kind` 在内核里是同一 `put` 的不同 payload 形状，语义映射仍需逐 kind 定义）。
>
> **角色纪律**：实现方不写测试、不改测试、不为测试加导出；评审方不改实现、不放宽断言。
>
> **口径**：本设计显式覆盖若干旧口径——采纳判据用**配对非劣检验**（不用"两臂 Wilson CI 不重叠"）；DAG 下**不设
> `MAX_REPEAT`**；池版本**增量 append-only**（不做全局 `world_version` bump）；契约术语统一为
> `inputs/outputs/pre/post`；适应度中 `λ` 罚成本、`μ` 罚结构。与旧口径冲突处，以本设计文档族为准。
>
> **六条跨文档写死口径（散落易读反，此处集中声明；细节各见对应机制文档）**：
> ① **OR 分支是拉式惰性**——路由在候选**求出之前**选边，只执行被选分支；"多路都跑再挑"必须显式建模为
> `cardinality:'n'` 扇出 + 聚合契约，两者不可互相顶替（《契约与图》§二）。
> ② **`model` 端口是效果端口** ⇒ `llm` 节点一律 `touches_effects:true` / `determinism:'audited'` /
> `idempotent:false`、**永不 memo**（《契约与图》§1.1）。
> ③ **`determinism` 全序为 `exact ≻ audited`**，"取 min" = 取更弱者（任一环节 `audited` ⇒ 生效 `audited`）。
> ④ **采纳闸的累计窗口随 `incumbent` 重置**，跨采纳不累计；升级触发只数"已判定"回合（《进化与账本》§一）。
> ⑤ **成本记账的唯一真源 = 成本事件流**（`CostEvent`，带 `attributed_to` 划分与 `counts_against_cap` 标志）；
> `cap` / `cost_exec` / `used_ext` / `search_cost` / `holdout_cost` / `verify_cost` / `encoder_cost` /
> `ratelimit_wait` / `cap_overshoot` 九个旧口径**全部降为对事件流的查询**，不再是独立记账面
> ⇒"搜索成本不得重复计进 `cost_exec`"由**构造**保证，不靠纪律（《契约与图》§2.2）。
> ⑥ **任务域必须分两族**：基线族（单点缺陷、单次调用可解，作对照）+ **不可解族**（四机制之一保证
> **单次调用**结构上不可解：上下文超窗 / 高单步失败率 / 冲突约束 / 不可逆首步）。两族**分开报**、
> **可解率下限各自达标**、不可解族另需**单次调用可解率不高于其上界**（两个阈值住账本）。
> 否则"编排有增益"先天不成立——那反映的是任务域选错，不是编排无用（两族机制见本节 §二 任务域）。

## 一、命题与主目标

**一句话命题**：在**固定预算**（LLM 调用数 + token + 工具调用 + walltime）下，一个运行时现场生成拓扑的 agent 图，
能否比人工设计的固定编排图拿到更高的隐藏测试通过率，且增益可归因到**编排 / 自治 / 进化**，而不是模型或参数量。

**唯一主目标（可测量）**：同预算 `B` 下，自适应臂相对人工固定图臂的隐藏测试通过率 `S_ag` 更高，判据为
**同任务同 seed 配对的差值单侧 CI 下限 ≥ Δ**（**BH-FDR 校正族 = 分层归因各档**：按难度向量 / 契约 / 自治档位分桶，
见 §1.3 五自变量；整体点估计 + Δ 并列报告）。
`S_new(holdout) ≥ S_incumbent(holdout) − ε` **不属于主目标**——它是采纳闸在检查点回合的非降条件（见《进化与账本》）。
`Δ / ε / δ / floor` 以数据 def 形式住账本（可版本化、可回滚、可人工改）；**阈值由机器从指标重算，禁手写 `passed`**。

**口径分工（两处不可混用同一阈值）**：

- **目标命题**（`S_ag` vs `S_fixedgraph`）用 `Δ`：**配对差值单侧 CI 下限 ≥ Δ**（同任务同 seed 配对，BH-FDR 校正；
  点估计并列报告）。主结论不能只用点估计，否则真 LLM 方差会把噪声读成增益。**BH-FDR 校正族 = 分层归因各档**
  （难度 / 契约 / 自治三表的分桶检验），整体单一检验无须 BH-FDR。
- **采纳闸**（`new` vs `incumbent`）用**配对非劣检验**（单侧 CI 下限 ≥ −δ，且对 CI 半宽另有约束）。

前者是"比人工图强多少"，后者是"本世代有没有退步"，不是同一件事。

### 1.1 预算 `B` 的可操作定义

- `B` 是**向量 cap**：`{ calls, tokens, tool_calls, walltime }`，四项上限**同时生效**，任一触顶即停。
  **`walltime` = 有效挂钟预算**（含 IO 与 LLM 网络等待，不区分 CPU/IO）；**限速退避的等待时长不计入
  `walltime` cap，单列 `ratelimit_wait`**，否则"配额枯竭"会被读成"能力不足"。默认**串行拓扑执行**；并行化会改变 walltime，
  列为升级阶梯一档，且须先解决并行下 publish 偏序问题（《契约与图》§2.2）。
- **控制层推理与搜索都要计费，但分两层记账**：**运行时**控制层（编排/分解/路由）的 decode token 进本任务 `B`；
  **离线搜索**（MCTS/EA 展开）不是单任务的属性，记在回合预算 `ROUND_B` 并单列 `search_cost`，
  **不得**摊进 `cost_exec(G)`。不记它 ⇒ 适应度系统性低估自适应臂的成本，主判据当场偏袒本方案。
  **搜索进运行时档**：搜索成本按当轮实际评测任务数 **等额** pro-rata 计入对外四维 `used_ext`
  （`search_cost_d / n_eval_tasks`，未评测任务不分摊；所有臂共用），但**仍不进** `cost_exec(G)`。
- 主判据读 `S_at_cap(B)`：**在 cap 下**的成绩。同时**必须报两个方向**——① 等预算比成绩（`S@B`）；
  ② 等成绩比成本（`cost_to_solve`）：报四维 `{calls,tokens,tool_calls,walltime}` 的**帕累托前沿**
   （哪些臂不被任何臂在所有维度同时支配）+ 各维中位数。**对外四维 `used_ext` 必须含编码器成本与
    （搜索进运行时档下的）pro-rata 搜索成本**，否则帕累托低估自适应臂的真实成本；适应度内部的标量 `cost_exec(G)`
    **只含图执行的确定性三维** `{calls, tokens, tool_calls}`，**不含 `walltime` / 编码器 / 搜索成本**，且**不进对外结论**
    （`walltime` 不可逐 run 复现，进 fit 会让软闸曲线随续跑翻面；它仍进 cap 硬停与 `used_ext` 帕累托；
    两臂省不同维度时排序不得依赖主观权重）。两个向量口径不同、不可混用。某臂只用 30% 预算就达到同成绩，这是它的优势，必须让它可见。
- **walltime 维不可逐 run 复现**（含 IO 与 LLM 网络等待）：`cost_to_solve` 帕累托的 walltime 维用**中位数 + 自助 CI**
  标注不稳定，**不进"断点续跑结论等价"的硬约束**（该硬约束只作用于确定性维度 `calls`/`tokens`/`tool_calls` 与
  `pass@1`/`S`）；否则续跑 walltime 必变 ⇒ 前沿漂移 ⇒ 成本结论被噪声推翻。
- **任务级成功 = 隐藏测试全过**（`pass@1`）；另有 `test_pass_fraction`（用例通过比例）作 dense 信号。
  两者都报，**适应度只用前者**。

### 1.2 两条硬约束

1. **holdout 只准"冻结模型前向 + 真测试判分"**。搜索器、llm teacher、任何"为提升而跑"的循环**一律只在 dev 上运行**；
   蒸馏集里不允许出现任何由 holdout 任务驱动的拓扑。一旦在 holdout 上搜过，holdout 即刻作废。
2. **同预算的第一性是 cap 而不是等量**：所有臂共用同一 cap、允许提前停止；不允许给自适应臂更大的 cap
   再用"同预算"话术掩盖。

### 1.3 五个自变量必须分开记账

| 自变量 | 对照 | 测量 |
|---|---|---|
| 编排 | 图固定 vs 现场生成 | 同池、同权重、同预算下的 pass@1 差 |
| 分解 | 固定分解（teacher 单次产出） vs 蒸馏分解（含再分解） | 固定分解下只搜拓扑的增益差；分解本身**不进搜索** |
| 路由 | 同图随机路由 vs 学到的路由 | 随机路由臂的 pass@1 差；**该列只在 `any_port_density` 达标时可读** |
| 自治 | L0 vs L1 vs L2 | 同图骨架（pin 同一张 reference 子图）、只改**实例**自治档位 |
| 进化 | 池冻结 vs 可结晶生长 | 跨世代曲线 + holdout 非降（跨世代 lineage 对照） |

> **五个自变量不是完全正交（明写，防"五表相加 = 总增益"的误读）**：编排与分解共用编码器与主干权重、
> 路由贡献只在编排产出的 OR 分支上存在、进化改的是编排可寻址的池。因此**分层归因表是"在其它档位固定下的边际贡献"**，
> 各列**不可相加**得到总增益。报告须写明每列的固定条件（哪些 pin 了、哪些随之变化）；
> 只有"自适应臂 vs 固定图臂"的总差值是主命题，分层表只用于定位增益来源。

> 分解、路由是独立模型，但其增益**默认并入"编排"列**汇报；要单独归因时必须挂对应消融臂，不许用"并入"话术掩盖。
> 编码器同理：**冻结编码器 + 随机编排**臂隔离编码器对泛化的贡献。控制层内思考同理：**关思考臂**（同权重同容量、
> 思考预算置零）隔离思考贡献——思考只花预算、不拿权限、不外挂 LLM。

## 二、任务域

**任务规格（task spec）**：`{ id, repo 模板, 起始提交, 任务描述, 隐藏测试, 预算上限, 难度向量 }`。

- **判分 = 真跑隐藏测试**（不是模型自评）：`exec` 端口在临时工作区执行；产物路径回写校验。
- **测试完整性**：评测用测试文件哈希 == 钉死哈希；改/删/新增测试文件 ⇒ 任务分 0。
- **holdout 隔离**：holdout 用**不同 repo 模板族**，不是同模板换参数——否则测的是记忆不是能力。
- **难度向量参数化**（课程模型的自变量）：文件数 / 接口数 / 约束数 / 不可逆步骤数 / 隐含依赖数 /
  **必读上下文量（相对模型窗口）**。**"复杂"必须是向量，不是标签**。
- **任务域必须含"单次调用结构上不可解"的一族**（否则主命题先天不成立）：若全部任务都能被一次强模型调用做对，
  单节点臂就会打平、"编排有增益"当场塌——而这与编排是否真有用无关，只说明任务域选错了。
  故任务域**分两族**：① **基线族**（单点缺陷修复，可单次调用解决，作对照基线）；
  ② **不可解族**，用四种机制之一在结构上排除单次调用：**上下文超窗**（必读代码量 > 窗口，必须分解分片）、
  **高单步失败率**（单次通过率低于上界，必须 critique-repair 回路）、**冲突约束**（需显式权衡择一，必须多方案+评判）、
  **不可逆首步**（选错则全废，必须先规划）。四机制分别对应分解 / 编排 / 编排 / 规划四个自变量。
  **两族都必须 oracle 可解**（长预算、允许多次调用）——"不可解"指的是**单次调用**不可解，不是任务无解；
  否则"不可解"会被误读成"编排无效"。两族**分开报**，主命题判定用合并簇级配对但必须并列分族结果。
  「单次通过率上界」与「可解率下限」两个阈值住账本。
- **dev / holdout 无交集**：任务哈希集合与 `expected` 不得出现在提案上下文、提示词、记忆召回里（含 JSON 内嵌）。

**沙箱最小版**：临时工作区目录 + 路径白名单 + 超时 + 默认无网（网络只在 `model` 端口 ⇒ `model` 属效果端口集）。

**工作区生命周期（写死，否则跨任务/跨臂污染）**：每个 `(task_id, arm, seed, attempt)` 一个**全新临时工作区**，
从 `start_commit` 干净实例化；执行结束后按 `artifact_paths` 白名单收产物哈希，然后**整目录删除**。
**同一任务在同一 run 内被多臂评测 ⇒ 多个互不可见的工作区**；禁止复用（复用会让前一臂的产物成为后一臂的隐式输入，
配对比较当场失效）。工作区路径**不进任何哈希与 `sig`**（否则重放不可复现）；
产物哈希只取**内容**，不取绝对路径。

## 三、红线

- **不改测试**、**不手写 `passed`**、**阈值由机器从指标重算**。
- **回合锚**：本轮评分引用钉死的 bench/scorer 哈希；提案改判据只影响下一轮。
- **holdout 绝不进**提案上下文、蒸馏集、提示词、记忆召回；**禁用 llm 打分 holdout**。
- **禁时钟驱动生长**：一切结构/池变更必须先有可署名的能力缺口或漂移证据。
- **禁运行时自改控制层结构**（只能走提案 → 门禁 → 采纳 → 可回滚）。
- **所有变更可回退**：一次变更 = 一条 `Entry`；回滚 = 一条追加，不删历史。
- **绝对性能数字不入规格文本**：只写比率、量级与测机。
- **如实红**：任何门禁红了就红着记录，先登记后扩展，不放宽断言、不改阈值。
- **无证据的增长**：一切采纳必须落一份 run + manifest；说不清来源的变化不许合并。

## 四、本设计不做什么

- **不含实现步骤、算法伪代码、具体阈值与默认值**（阈值与默认值以数据 def 形式住账本，见《进化与账本》§二）。
  **本文族只写设计（结构 / 语义 / 不变量 / 接口）**；实现过程与阶段排期不属本文族。
  设计文档之间可互引，但**不得引用任何计划文档**——否则"为什么这么设计"与"先做哪一步"会缠在一起，
  改阶段就要改设计文档。
- 不接内核：实验独立 standalone；账本形状对齐内核，但搬迁是后置档。
- **"不接内核"是实验期的选择，不等于"生产可行"**——本实验只证明
  「机制 M 在（任务分布 D, 池 P, 成本模型 C）下有效」，**不证明**（D′, P′, C′）下有效。
  三轴正交、不可互推：**① 代理 vs 真 LLM**（分界 = 该 run 结果是否进结论）、
  **② 实验 vs 生产**（分界 = 是否接内核、插件是否真实）、**③ 合成 vs 真实任务**（分界 = 任务来源）。
  **一切产证据的 run 一律真 LLM**（自实验开跑即生效，不是某个阶段的属性）；代理只跑 CI/调试。
  **六项迁移落差**（验证器 / 池规模 / 特征面 / 成本量纲 / 运行时两套代码 / 固定图臂公平性）
  与**迁移假设清单**是**结论报告**的必出交付物——否则"实验全绿"会被读成"可以上生产"。
- **落差①「验证器」的定义与地位（最深的一条，必须单独说清）**：**自动验证 = 一段程序在无人介入下判定
  "任务做对了没有"，给出 0/1 或分数**（实验里就是 `verify()` 跑隐藏测试）。
  飞轮的第二步"判断哪些图做对了"完全依赖它：没有成功信号，搜索无法定向、蒸馏没有 target。
  **主项目是通用插件运行时 ⇒ 生产里不会有统一的自动验证**（代码类有测试，调研 / 写作 / 多步操作没有）。
  部分缓解：设计有两级验证——**任务级** `verify`（飞轮依赖它）与**节点级** `post`（信用分配用）；
  节点级性质（能编译 / JSON 合法 / diff 干净 / 类型检查过）在通用域里往往仍可自动判，
  故飞轮可退化为"用节点级 `post` 当代理信号"，但那**有偏**（优化"每步看起来对" ≠ "任务做对了"）。
  ⇒ 该落差**必须由 `probe-real` 变体②（弱监督探针）在实验内测**，测不出结论就必须给出替代监督源登记提案。
- **`probe-real` 迁移探针（结论报告必跑，两个变体）**：真实感契约池 + 真实开源 PR 反向构造的任务，
  **明标污染、绝不进主命题 / 训练集 / holdout**，报告里与主表物理隔离。
  变体① 测域迁移（D′/P′），变体② **把任务级验证从搜索中遮掉**、只留节点级 `post`，测落差①。
  **只报方向不报显著性**（样本量小）——它是探针不是实验，措辞必须写明。
- 产品化桥（迁内核 + 真实插件池）是**产品化路径的必做项**，不是可选项
  （触发条件 = 决定产品化，不是运维信号）。
- **不做主项目那套 model 适配器 / vendor 抽象、UI（含最小对话界面）、通用 tool 框架、Rust/容器 sandbox、
  通用 scorer 框架、memory、skill、MCP、多 agent**（多 agent 角色分离是升级阶梯上的一档）。
- **但本实验自带最小实现，不是"什么都不做"**：`adapters/llm_gateway.ts`（唯一 IO 边界，`model.kilo` / `model.replay`
  同门）、`exec` 沙箱最小版（目录隔离 + realpath 白名单 + 超时 + 无网）、任务级验收器（跑隐藏测试）、
  合成任务生成器与 bench 池、toy tool 节点。**"不做" = 不做通用框架与生产级实现**，
  不是"实验里没有 model / sandbox / scorer / bench"——它们是**实验必需件**。
- 不定义尚未写死的细则（沙箱白名单具体条目、模板族参数终值等）——未定义项必须在实现前补齐，
  不许"顺手自己定"。
