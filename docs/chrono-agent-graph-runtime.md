## 一、控制层

> **口径**：本节"零 LLM"指控制层本身不含 LLM 端点调用。控制层是可训练的**小规模**神经网络（容量上限住账本），使用固定 LLM **编码器**（表示层）和 LLM **manager**（进化外环）作为外挂组件，不计入控制层；前者成本计入预算，后者记外环预算。

三模型 + 课程独立：

| 模型 | 输入 | 输出 | 训练信号 |
|---|---|---|---|
| **分解**（含规划） | 任务描述 + 难度向量 + 上下文 | 子目标序列（含目标态） | 蒸馏自搜索/教师的分解；成功轨迹的正样本 |
| **编排** | 任务 + 子目标 + **能力类池** + 历史统计 + 搜索提示 | 拓扑（token 序列 → 受约束解码） | expert iteration：搜索/教师产好图 → 监督蒸馏；**终局稀疏奖励不直接训** |
| **路由** | 该 `any` 端口的 obs（**已产出 slot 摘要 / 已执行能力集**、预算余量、**各候选边的静态特征**；拉式惰性下**不含候选产物内容**） | any 端口选边 | 主：搜索 / teacher 选边监督；辅：被选中节点的 `post` dense + 局部成败（过程特征，step 级标签、回合末离线更新；执行期权重冻结） |
| 课程 | 世代统计、失败模式、漂移 | 任务/难度调度 | 外环信号（稀疏，允许） |

**MoE 的归属（用 MoE，但它只是编排模型的内部稀疏层）**

- **MoE 不是独立的路由器模型**。否则"MoE 路由选能力类"与"编排模型生成含能力类的图"会对同一件事各投一票，
  训练信号互相干扰、归因不出。落法：**MoE 是编排模型内部的一层，且按生成位置运行**——每个 `NODE` 位置以
  `子目标编码 + 当前部分拓扑特征（已生成契约、未闭合 required 端口、剩余预算）` 为 gate 输入，输出 top-k 专家，
  专家输出喂给解码器产出该位置的 `contract_idx`；**"路由模型"只做图内步进选择**（在已生成的拓扑上为 `any` 端口选边；实例选择是运行时确定性规则，见《契约与图》§1.1，不经路由模型）。
  **不是"一个子目标只 gate 一次"**——否则单子图内无法生成多契约，且位置级 gate 辅助损失（见本节 MoE 归属）无对齐点。
- **gate 与解码 mask 的关系（写死，否则 top-k 会和 mask 打架）**：gate 选的是**专家**（= 契约），
  而解码 mask 会把**当前位置不合法的契约**（`allowed_cap` 为假：无兼容前驱、无输入端口却非首位、闭合预留失败）全部禁掉。
  执行顺序固定为 **先算 mask，再在合法集合内取 gate top-k**：`cand = topk(gate_logits ⊙ mask, k)`。
  若 mask 后合法契约数 `< k`，则 **k 退化为合法数**（不补非法专家），并记 `gate_k_shrink` 诊断；
  若合法集合为空 ⇒ 那是**池不变量或解码器被破坏**，门禁直接判红（断言失败，不是回退路径），**不是**放宽 mask。
  **gate 辅助损失只在"搜索器选的契约本身合法"的位置上计**（否则会训模型去选被 mask 的专家）。
- 专家 = **能力类（契约）**，闭集 append-only；执行层选择 = 契约 → 实例。
- 兜底/未知能力专家必设；负载均衡损失防坍塌；`top-k`、专家数、参数量进版本并计入 MDL 惩罚。
- 陷阱：专家边界**必须**是契约，不能是实例——否则池生长 = 改模型结构。
- **契约扩展 / 迁移 / gate 稳定性（不变量）**：gate 随专家数**追加式扩展**（冻结旧列、新专家列零初始化）；
  arch bump 时旧专家权重按专家 id 可加载、新专家零初始化，且必须过"旧权重可加载 + 旧金丝雀不回退"的迁移门禁，
  否则回退旧 `ver`；重训只在被激活专家 + 受影响节点上做；加节点级辅助损失稳定 gate 与专家对齐。

**路由的训练信号与信用分配（写死）**：any 端口选边的主监督 = **搜索 / teacher 轨迹中该端口的选边**
（与编排同源的 expert iteration，**不用 REINFORCE 作主路**）；辅助信号 = 被喂节点的 `post` verdict（dense 主）与局部成败
（过程特征）。每次选边记 `edge_choice`，与 `post` 通过 `(task_id, step, node_index)` join；无监督样本时该步只记辅助信号。
**权重在执行期内冻结**；dense 标签按 step 落盘，每回合与编排一并离线更新。**禁止执行期 SGD**（否则逐步改权 ⇒ 不可逐字节重放）。
所谓「在线」指标签粒度是 step，不是执行期更新权重。

**控制层内思考（intrinsic thinking，不外挂 LLM；写死）**

- **思考是模型自己的**：三个控制模型（分解 / 编排 / 路由）在产出最终输出前，先在自己的受约束解码里产出**思考 token**（`THINK` 段）。
  `THINK` **不进拓扑**（`sig(topology)` 与编译期均忽略）、不产契约 / 节点、**不跑能力类 gate**（gate 仍只在 `NODE` 位置运行；
  gate 辅助损失的对齐点按 `NODE` 位置计数，`THINK` 不计入位置编号）。
- **不外挂 LLM ⇒ 三条不破**：无 LLM 端点调用 ⇒ 控制层仍"零 LLM、可 CPU 训练、可逐字节重放"；思考 token 按**控制层 decode token**
  计费（沿用既有口径），进轨迹与预算账。
- **上限与停机**：单次思考 ≤ `MAX_THINK`、路由每任务思考总量 ≤ `MAX_THINK_TASK`（住账本）；模型吐 `THINK_STOP` 或触上限即停，
  两者都确定性可重放。思考受任务 `B` 约束——**`MAX_THINK` 是上限不是保底**。
- **训练信号（主路，写死）**：THINK 词表 = `{THINK, THINK_STOP}`（一元计算步；**禁止**把契约 / motif 放进 THINK，否则等于偷生成节点）。
  搜索中间量经 **readout 头**对齐，不是 THINK token 本身：
  ① 编排：MCTS 主变分路径 PV 的第 `min(i,|PV|-1)` 步动作（第一层 expand：motif/契约）作 think 步 `i` 的 `action_head(h_i)` 目标；`value_head(h_i)` 回归搜索 V 或终局 `pass@1`；
  ② 分解：teacher 计划 token 作思考目标（序列 CE）；
  ③ 路由：每次 `any` 选边前的 THINK 对齐该端口的搜索/teacher `edge_choice`，value 标签 = 被喂节点 `post`。
  `|THINK| > |PV|` 的多余步只算 value、不算 PV 动作。无搜索样本时 ⇒ `L_pv=0`，只留 listwise / 真验收 value。
  **`action_head` 的动作空间（写死）** = `契约集（上限住账本）∪ motif 库当前条目`。motif 库随池版本增长 ⇒
  **`action_head` 输出维随之追加式扩展**（旧列冻结、新列零初始化，与 gate 同一迁移规则），
  并进 `arch` 的 `{池版本, 图文法版本, 精确 dims}` fail-fast 检查。**motif 库上限 = `MOTIF_MAX`（住账本）**；
  触顶后按 `sub_sig` 的**使用频次**淘汰最低者（淘汰记 `note`，被淘汰 motif 的 `action_head` 列**不复用**、置零冻结）。
  不设上限则 `action_head` 维度无界、arch 每回合都变、旧权重全废。
  **stop-gradient**：`L_think`（PV CE + value + 可选停机）**不**更新图解码头；`L_listwise` **可以**经 THINK 隐状态回传到思考模块（思考必须对最终图有用）；`L_gate` 只在 `NODE` 位置，THINK 不计入位置编号。
  主损失仍是最终图 / 分解的 listwise；思考损失权重进版本并计入 MDL。
- **容量口径**：思考模块参数计入控制层；**容量上限分两档，取值住账本**（默认档 / 容量档）。出现**欠拟合诊断**时走「控制层容量」档
  （arch bump + 重训 + 参考前向自检），上限登记后升——**不静默突破**。
- **可归因**：新消融臂「**关思考**」（同权重、同容量、**思考预算置零**）——思考贡献必须与编排 / 容量分开报。
- **备选形态（登记，不默认）**：潜思考步（latent 循环 / 自适应计算）——无 token 可计费，需另定计费与停机口径，故后置。

**表示层（任务/子目标怎么变成向量）**

- 自然语言任务与子目标**必须过固定编码器**：结构化字段（难度向量、契约 id、预算余量）走白名单特征；
  自由文本走**固定 LLM 编码器**（`encoder_pin` 进 manifest）。
- **编码器分两级**：① **任务/子目标自由文本**走固定 LLM 编码器（`encoder_pin` 进 manifest），
  同一任务全程**只真正编码一次**（缓存），但**每臂每任务按同一 `encoder_cost` 名义等额计费**（实际走缓存），
  使对外四维 `used_ext` 跨臂可比；② **逐节点 obs（产物 / slot / 进度特征）**走**确定性白名单特征**，
  不进 LLM 编码器、不产生额外调用成本（其计算成本已含在控制层 decode 内）。
- **子目标文本也过编码器 ⇒ 分解模型的输出必须可编码**：分解产出的子目标是**自由文本**，编排要吃它就得再编码一次。
  因此 **`encoder_cost` 按"任务描述 1 次 + 子目标 `m` 次"计**（`m` = 该任务分解出的子目标数），
  名义等额计费的基数是 `encoder_cost(task) + m · encoder_cost_per_subgoal`；
  `m` 由分解模型决定 ⇒ **不同臂的 `m` 可能不同**，故该项**按各臂实测 `m` 计**，
  只有"同一任务同一 `m` 下的单次编码成本"是等额的。固定分解臂的 `m` 由 teacher 单次产出、全臂共用。
  **`MAX_SUBGOALS`（住账本）** 封住 `m`，否则分解模型可用"多切子目标"无限扩编码预算。
  编码器调用成本**计入本任务 `B`**（不得剥离出 cap），单列报告 `encoder_cost`，**不并入 `cost_exec(G)`**；
  对外四维 `used_ext` **含** `encoder_cost`。**逐节点 LLM 编码列为后置升级档**（单独计费与归因）。
- 编码器不参与训练 ⇒ 控制层仍满足"零 LLM、可 CPU 训练、可逐字节重放"；但**它一旦换版本，全部历史权重作废**
  （特征语义变了），所以 `encoder_pin` 必须进 arch 的 fail-fast 检查。
- **编码器贡献必须可归因**：冻结 LLM 编码器可能承载跨任务语义泛化、掩盖编排贡献。
  「冻结编码器 + 随机编排」臂隔离编码器贡献；归因报告单列"编码器消融列"。
- **编码器由编排与分解共用、head 独立**：编排模型与分解模型均吃任务 / 子目标自由文本，共用同一 `encoder_pin` 特征、各 head 独立；**路由模型输入为确定性白名单特征、不进 LLM 编码器**（见上文两级）。**dense → 编排的信用分配经 `edge_choice` ↔ `post` 按 `(task_id, step, node_index)` join 的数据通路**，不依赖路由与编排共享权重。

**特征不变式**：`NODE_SLOT` 追加式稳定槽；`cand_mask` 变长 bitset；控制层 dims **与节点实例数无关**；
`weights.json` 的 `arch` 记 `{池版本, 图文法版本, 精确 dims}`，不符 **fail-fast**，禁跨版本静默加载。

## 二、运行时与自治

**解析执行（拉式惰性）**：运行时读**已编译的调度计划** → 从 `sink` 反向 `demand` → 遇 `any` 端口先由路由选边、
再只求值被选前驱 → 节点产出经 typed 校验 → `sink` 完成或预算触顶 → 交验收。
**拓扑的唯一来源是编排模型**（L3 除外）。求值顺序与 `branch_not_taken` 口径见《契约与图》§二「活动子图的执行语义」。

**拓扑是 AND-OR 图、执行是路由实例化**：编排生成的是**条件超图**（含分支 / 扇出 / 多出边，`binding_mode:'any'`
端口即 OR 候选），路由模型在运行时**为每个 `any` 端口恰选一条边** ⇒ 实际执行的是超图的**活动子图**。
故：`sig(topology)` = **超图签名**（去重 / 对照用）；`pass@1` 测的是**路由实例化执行**，不是超图本身；
「拓扑打乱」臂测超图携带的信息量，「同图随机路由」臂测路由贡献——两者**正交**，须分开归因。
默认串行拓扑执行。

**执行前先编译**：`GraphDef → 静态类型检查（含 `all/any` 与类型兼容、**同键 publish 偏序 / 互斥分支 join**）→ 调度计划骨架 →
执行期按路由逐 `any` 端口实例化活动子图 → executor`。**活动子图不能在执行前定死**——它取决于路由对 `any`
端口的选择，而路由 obs 含"已产出 slot 摘要 / 剩余预算"这类运行时量；编译期只做静态可判的部分（类型、可达性、上限、publish 偏序）。
静态检查失败记 `compile_reject`（不计入图文法门禁）；运行时只执行已编译计划 + 逐边实例化，不做语义兜底。

**预算触顶时的收口（写死）**：拉式惰性下"预算耗尽"发生在某次 `EffRequest` 拒发处（见《契约与图》§2.2 cap 粒度）。
此时**不做任何补救执行**：当前节点得 `refusal(budget)`，尚未求值的节点全部记 `branch_not_taken`，
任务判 `incomplete`（进 `S@B` 分母、不计 `fail`）。**验收仍照跑**——若 `sink` 已产出合法产物，
任务级验收器照常判分（可能仍 `pass@1=1`）；`sink` 未产出 ⇒ `pass@1=0` 且标 `incomplete`。
"提前停但做对了"与"提前停且没做完"必须分开可见。

**自治档位（L2 第一版开）**

| 档 | 节点能做什么 | 约束 | 默认 |
|---|---|---|---|
| **L0** | 纯函数：一次调用出结果 | 无 | 工具节点 |
| **L1** | 内部有界循环：自检、重试、**请求追加输入**、拒绝并给原因、换工具 | 迭代上限 K、预算上限、退出条件由节点参数**声明**（可版本化可回滚） | LLM 节点 |
| **L2** | **子目标委派**：把子目标交回编排模型现场生成子图 | 递归深度 ≤ `MAX_RECUR`、预算切分、子图过同一图文法闸 | 可选节点 |
| **L3** | 自己产出子拓扑（绕开编排模型） | 仍过同一图文法闸 + 同一预算账 + 同一审计流 | **登记待决，先不开** |

**三条自治不变量**

1. **自治只能花预算，不能拿权限**：不得调未声明端口、不得越出已声明 caps。
2. **自治决策必须留痕**：每次"节点自己决定"（重试/请求输入/委派/拒绝/换工具）产出一条记录
   （节点 id、决策类型、消耗、结果）。这是**监控指标层的一等输入**——失败模式聚类直接落在决策流上。
3. **自治不改变可寻址面**：对外仍是 typed 契约；自治是内部实现细节。

**L1"请求追加输入"必须声明式**：L1 节点能"请求追加输入"，但可请求的输入键集合必须在契约 `reads` 中
**预声明**（标 `optional:true`，带"运行时按预算供给"语义）；运行时按剩余预算决定是否供给。**不许运行时动态请求
未声明键**——否则违反"未声明读不可见"，且让归因（节点行为只由声明依赖决定）当场失效。
**只能请求 shared 键、不能请求上游节点求值**（见《契约与图》§二末条）：`request_input` 若被允许触发新的前驱执行，
活动子图就在执行期变形，`(拓扑, 选边) → 活动子图` 的唯一性当场失效。
**供给判据必须确定性**：`supply(key)` 当且仅当 `remaining_d ≥ supply_cost_d(key)`（四维全满足，`supply_cost` 是
该键的 pin 住的先验），否则 `refuse(budget)`；不许用"看着还够"这类运行时启发。

**自治档位与契约的关系（写死，堵档位漂移）**：`autonomy` 在 `NodeDecl` 上（实例属性），**不在契约上**——
同一契约可有 L0 与 L1 实例。约束：① `autonomy:L1` ⇒ `bindings.retry_policy` 必填；
② `autonomy:L2` ⇒ 契约 `can_delegate:true`（反之不必）；③ 档位是**实例选择的一部分**，
  故**自治档位消融必须强制指定实例**（走 harness，不走 `choose_instance`），否则档位与实例健康分混淆。

**为什么 L3 先不开**：它会让"拓扑唯一来源"破功（一个学的、一个节点现场拍的），归因不清。

## 三、训练与数据飞轮

**搜索的定位**：搜索是**数据生产手段**（产蒸馏目标），**不是运行时的组成部分**。运行时默认只跑编排模型的
前向；"搜索进运行时"是升级阶梯上的一档，不是默认态。

**主路 = search/teacher → 目标 → 蒸馏（expert iteration）**：

1. 搜索器（MCTS / EA / 有界 beam）在真验收下搜索拓扑；
2. 好图-任务对入库（只认验收通过；对抗套件前置过滤，防 hack 验收器）；
3. 蒸馏进编排/分解模型；路由用节点级验收信号（step 级标签）在回合末与编排一并离线更新；
4. 用新权重再搜（回到 1）。

**搜索空间必须分层（三个变异面耦合搜会爆预算）**

| 层 | 搜什么 | 代价 | 谁做 |
|---|---|---|---|
| 结构 | 拓扑（受约束解码空间内的增删 / 重连 / 分支 / 合流） | 高（每次都要真跑验收） | MCTS / EA |
| 绑定 | 提示词 / 模型 / 解码参数（不占生长额度） | 中（可缓存、可 A/B） | 有界 beam / 网格 |
| 分解 | 子目标序列 | 低 | **只由 llm teacher 与蒸馏产出，不进搜索** |

**`value head` 不是独立模型**：它是**编排模型的辅助输出头**（与 gate 辅助损失同档），参数量与 MDL 计入
编排模型，训练信号 = 验收通过 + 成本惩罚；不单列模型、不单列预算、不进模型清单。

**蒸馏目标：visit 分布 / 帕累托采样、集合级，禁 one-hot**（多解是本域的结构性事实，不是噪声）

- 搜索对同一任务通常产出**多张同样验收通过**的图（多解）。**用单张图的 one-hot 序列 CE 会摊平**；
  均匀软化反而掉分。
- **软目标按下列优先级取一（写死，不再并存两套权重）**：
  ① **visit 分布（AlphaZero 风格，首选）**：搜索 visit 分布天然非均匀、携带搜索置信，天然满足"禁均匀软标签"；
  ② **帕累托采样（visit 不可得时的退化档）**：从同任务好图集合里按"成本-复杂度**帕累托前沿**"采样——
  前沿上的图**等权**、被支配者降权；损失 = **集合级 softmax（listwise）**；③ 单解任务退化为普通 CE。
- **visit 分布与 listwise 的接口（写死，堵"两套目标混用"）**：MCTS 的 visit 分布是**根节点动作分布**
  （每个动作 = 第一层 expand 的 motif/契约），而 listwise 的候选是**完整图**。二者按下式桥接：
  **候选集 = 该任务搜索到的全部验收通过图**；**图 g 的目标权重 `p*(g) ∝ N(g)`**（`N(g)` = MCTS 中
  `sig(g)` 对应终局状态的累计访问次数，未被访问到的通过图取 `N=1` 作平滑）；损失 = `CE(q, p*)`，
  `q(g) ∝ exp(s(g)/τ)`。**根动作 visit 分布只用于 THINK 的 PV 监督**（§THINK 训练信号），**不直接当 listwise 目标**。
  两者混用会让"第一步选什么"和"整图长什么样"共用一个 softmax、梯度互相污染。
- **变长图的 listwise 口径（写死）**：模型对图 g 的分数按 **token 数长度归一**：
  `s(g) = (1/|tokens(g)|) · log p_θ(g)`，`q(g) ∝ exp(s(g)/τ)`。**不归一会让长图总 log-prob 系统性偏低 ⇒ 小图偏置**，
  与"禁小图偏置"冲突；**不加成本 / 复杂度权重**（禁 `1/(成本×复杂度)`）。
  **长度归一的已知副作用（明写）**：归一后模型可通过"生成更长的图"稀释每 token 的负 log-prob ⇒ **大图偏置**。
  两个偏置方向相反，靠既有的「蒸馏目标 `|V|` 分布 vs 搜索产出 `|V|` 分布」诊断双向监控：
  分布**系统性偏小**⇒ 采样过强；**系统性偏大**⇒ 长度归一过强，走登记提案改归一指数
  （`s(g) = |tokens(g)|^(-γ) · log p_θ(g)`，`γ` 住账本），**不许**私自加成本权重回来。
- **禁止 `1/(成本×复杂度)` 全集合加权**：它对大图双重惩罚，会蒸馏出"总生成最便宜最小图"的偏置（小图泛化差）。
  必须报"蒸馏目标 `|V|` 分布 vs 搜索产出 `|V|` 分布"，分布系统性偏小 ⇒ 采样过强，调权重。
- **禁止**均匀软标签；**禁止**只取搜索到的第一个解（会引入搜索顺序偏置）。

**holdout 禁搜**：搜索与 teacher 只跑 dev。

**信号分层（明确声明）**：

- **dense（主）** = 节点级 `post` verdict（dense 的唯一来源，见《契约与图》§1.1）；**局部成功/失败与预算消耗为过程特征，单列、不并入 dense 主定义**。
- **中（主）**：搜索与 llm teacher 产的图/分解目标 → 监督蒸馏。
- **稀疏（外环）**：会话成败、漂移判定、采纳门禁、课程调度。**不用它直接训编排模型**，理由不是"稀疏学不会"，
  而是：① 采不到正样本时它是**恒零信号**；② 它不给跨节点的信用分配；③ 本域已有 dense 的节点级验收器。

**口径修正**：曾用某实验的 follow `0.0000` 论证"稀疏 RL 打不过密集监督"，**该读法作废**。事实是随机初始化策略
几乎采不到正样本 ⇒ **无信号，不是学不会**。教训：**探索必须被引导**——这正是本设计把搜索器与课程模型列为必需件
（而非可选件）、并把节点级验收器当主信号的原因。

**推论（新增一等可观测量）**：搜索器的**正样本产出率**（`solved/rollout`、`meanReward`）必须进每次报告——
它决定蒸馏集会不会饿死。若搜索器产不出正样本，故障点在搜索器，不在编排模型。

**推论二（expert iteration 退化监控）**：主路是标准 expert iteration，已知陷阱是**策略与搜索器共退**——
策略学搜索器偏置 → 引导搜索器 → 正反馈坍缩到少数拓扑族。须监控并报三个量：策略与搜索器各自拓扑族
（按 `family_sig` 分桶归一化）的香农熵，以及二者的 KL 散度。
**共退判据 = 散度与策略熵同向单调下降**——仅散度下降而搜索器仍多样，只说明策略追平搜索器，不算坍缩；
触发课程/探索干预。进报告必出列，与正样本产出率并列。
**KL 的支撑集问题（写死，否则 `Ei` 会变成 ∞ 或被平滑洗掉）**：`π_policy` 与 `π_search` 的支撑集不同
（策略会生成搜索器没探过的族，反之亦然）。口径：**支撑集 = 本回合两者出现过的 `family_sig` 并集**；
两侧各做 **add-one 平滑**（分子 +1、分母 + |支撑集|）后算 `D_KL`。
平滑常数与支撑集定义 pin 进 manifest；**跨回合比较 `Ei` 时必须同时报支撑集大小**——
支撑集变大本身会压低 `Ei`，不标注就会把"探索变多"误读成"共退加剧"。

**llm teacher 的红线**：teacher 只在 **dev** 上用；**holdout 判分只用隐藏测试**，**禁用 llm 打分 holdout**
（防自欺）。teacher 产出与提案文本一律过泄漏扫描。

**惰性训练**：只训被激活的能力类专家与受影响节点；触发条件与预算由外环登记。新能力类 = 新专家零初始化槽，
**旧专家权重不动**。
**"被激活 / 受影响"的判据（写死，否则惰性训练是空话）**：**被激活专家** = 本回合训练集里被搜索器/teacher
在任一 `NODE` 位置选中过的契约对应的专家；**受影响参数** = 被激活专家的专家层参数 ∪ gate 的对应列 ∪
**共享主干与各 readout 头（始终训）**。共享主干必须始终训，否则新专家永远学不会与主干对齐。
落法：对未激活专家的专家层参数与 gate 列做 **梯度 mask（置零）**，不是"不喂样本"——
只靠不喂样本，AdamW 的权重衰减仍会把未激活专家的权重慢慢衰减掉，"旧专家权重不动"就成了假承诺。
**未激活专家的 `wd` 也必须 mask 掉**，这条要进**参考前向自检项**。

### 3.1 数据飞轮

**定义**：飞轮 = "执行 / 搜索产数据 → 数据过闸进训练集 → 训出新权重或新节点 → 新权重产出更好的数据"的闭环。
本实验的飞轮**只在 dev 上转**；**holdout 是只读测速仪，不是燃料**。

**数据三层（版本化、内容寻址）**

| 层 | 对象 | 产出者 | 消费者 | 门禁 |
|---|---|---|---|---|
| **原始轨迹层** raw | 逐次执行 events、审计回灌、预算账 | 运行时（每次执行） | 诊断、重放 | 只增不改；随 run 冻结 |
| **训练集层** train | 「任务→图→结果」三元组、节点级 dense 标签、分解目标、搜索 visit 分布 | 搜索 / teacher / 执行 | 分解 / 编排 / 路由 / 课程四模型 | 对抗套件 + 泄漏扫描 + 去重 + 可重放校验 |
| **评测层** eval | dev / holdout bench、金丝雀集 | 任务生成器 | 门禁、漂移 | 钉死哈希；**holdout 只读** |

**四个消费者与各自的飞轮转速**

| 模型 | 吃什么数据 | 反馈时延 | 触发 |
|---|---|---|---|
| 路由 | 节点级验收 dense + 局部成败（step 级标签） | **每回合（离线更新；标签逐步落盘）** | expert iteration 同频；执行期权重冻结 |
| 编排 | 搜索 / teacher 好图集合 + visit 分布 | **每回合（离线蒸馏）** | expert iteration |
| 分解 | teacher 分解 + 成功轨迹正样本 | 每回合（离线蒸馏） | 同上 |
| 课程 | 世代统计、失败模式、漂移 | 每世代（外环稀疏） | 外环触发条件 |

**飞轮四条不变量**

1. **只在 dev 上转**：训练集不得含任何由 holdout 任务驱动的产物；泄漏门禁在**数据层再判一次**，不只判提示词。
2. **每条训练样本可溯源**：样本 → 轨迹 event → 任务 id → 池 / 权重 / 提示词版本；不可溯源样本不得入集。
3. **入库前过四道闸**：对抗套件（防 hack 验收器）、泄漏扫描、去重（内容寻址两级去重）、可重放校验
   （回灌下逐字节等价）。
4. **转速与退化可观测**：正样本产出率、Ei 散度、**训练集分布漂移**（新样本 vs 存量在难度向量 / 契约 / `|V|`
   上的分布）三项进每次报告；散度单调下降或正样本率枯竭 ⇒ **停轮诊断**，不许硬转
   （否则等于用退化数据喂退化模型）。

**三个已知断点（预先声明）**

- **燃料断点**：搜索器产不出正样本 ⇒ 训练集饿死。
- **反馈断点**：路由与编排均为每回合离线更新；回合过长会让 step 级标签堆积、课程来不及调分布。执行期仍禁止 SGD。
- **污染断点**：把 holdout 或"为提升而跑"的产物混进训练集 ⇒ 整条飞轮作废。
